# SCT_WD_1

This repository contains tasks and projects completed as part of the SkillCraft Technology Web Development (Level 1). It showcases core web development concepts and hands-on implementations using modern web technologies.

## Tech Stack

- **HTML5** – Semantic structure and page layout  
- **CSS3** – Styling, layouts, and responsive design  
- **JavaScript** – Client-side logic and interactivity  

## Features

- Clean, modular project structure  
- Responsive pages suitable for desktop and mobile  
- Focus on fundamental web development practices  

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shadab80k/SCT_WD_1.git
   ```
2. Open the project folder and launch any `.html` file in your browser.
